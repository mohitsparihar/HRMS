## 🚀 Getting Started

### 🛠 Clone and Setup

```bash
git clone https://github.com/mohitsparihar/HRMS.git

cd HRMS

npm install
```

### ▶ Run Dev Server

```bash
npm run dev
```

Uses `.env` environment configuration.
